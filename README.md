# image-editor
使用说明：直接点击image_editor.html即可开始图片编辑

 使用界面：
<img width="2548" height="1192" alt="image" src="https://github.com/user-attachments/assets/f410696b-bfeb-4a56-a3b6-b287dcba18a2" />

功能1：方框。 可添加方框+颜色填充，方框的粗细、颜色均可调。 对象可删除、拖动、旋转
功能2：直线。 可添加直线，颜色、粗细可选。 对象可删除、拖动，不可旋转
功能3：文字。 可添加文字，颜色、大小可调。对象可删除、拖动，不可旋转
